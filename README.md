# Замер скорости интернета

По умолчанию используется постоянная ссылка на тестовый файл OVH.
Можно передать свой URL.

Скрипт скачивает файл 10 раз подряд и выводит среднее время, объём данных
и скорость в Мбит/с. Файл на диск не сохраняется.

При таймауте, ошибке HTTP или неполном скачивании скрипт выводит ошибку
и останавливается. Таймаут — 30 секунд на сетевую операцию.

## Запуск

Python 3.9+, без зависимостей.

```sh
python3 speed_test.py
```

Тестовый файл — 10 МиБ. За запуск скачивается 100 МиБ.
Со своим адресом:

```sh
python3 speed_test.py 'https://example.com/file.jpg'
```
