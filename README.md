# Замер скорости интернета

Скрипт скачивает файл 10 раз подряд. Считает среднее время запроса,
общий объём данных и скорость в Мбит/с. Python 3.9+, без зависимостей.

## Запуск

```sh
python3 speed_test.py
```

По умолчанию скачивается тестовый файл OVH на 10 МиБ. За запуск — 100 МиБ трафика.
Можно передать свой адрес и таймаут в секундах:

```sh
python3 speed_test.py 'https://example.com/file.jpg' --timeout 60
```

Таймаут по умолчанию — 30 секунд на сетевую операцию. При ошибке замер останавливается.
Файл читается блоками, на диск не сохраняется.

Скорость считается так: `все скачанные байты × 8 / общее время / 1 000 000`.
Время включает соединение и полное скачивание. Результат зависит от выбранного сервера.

## Тесты

```sh
python3 -m unittest -v
```

Тесты используют локальный HTTP-сервер, без запросов в интернет.
